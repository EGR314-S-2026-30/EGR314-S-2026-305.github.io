Prototype page assets (course checklist)
=======================================

1. innovation-showcase-poster.jpg
   - A poster image is already checked in for the Prototype page.
   - Replace this file when you export an updated JPG from your design tool.

2. innovation-showcase-poster.pdf
   - Export the same poster as PDF from your design tool.
   - Place it here. The Prototype page links to this file.

3. Optional: final-rover-1.jpg, final-rover-2.jpg
   - Photos of the final integrated system.
   - Update paths in ../Prototype.md if you use different names.

After adding files, commit and push so GitHub Pages can serve them.

YouTube: upload demo videos, open each video > Share > Embed, copy the
iframe "src" URL (contains /embed/VIDEO_ID). Paste into Prototype.md in
the second (or third) iframe block.
